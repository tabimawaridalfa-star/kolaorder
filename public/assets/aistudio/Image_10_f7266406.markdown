## Brand & Style

The design system establishes a high-utility, agile point-of-sale and queue management environment specifically engineered for Indonesian micro, small, and medium food enterprises (UMKM). The system balances swift, single-thumb physical ergonomics with operational clarity under high-tempo kitchen and counter environments.

The visual direction uses a clean, modern, light-mode flat design approach, characterized by delicate 1px structural strokes, soft tinted surfaces, and restrained ambient depth. Heavy elevation and visual clutter are avoided in favor of strict visual hierarchy and information clarity:
- **Atmosphere:** Approachable, crisp, disciplined, and functional.
- **Audience:** Indonesian street-food vendors, warung owners, and busy restaurant cashiers operating single Android devices during peak meal hours.
- **Ergonomic Mandate:** All critical operational triggers (confirming queue status, stock updates, WhatsApp bot management) adhere strictly to a 44px minimum touch target, biased toward bottom-sheet interactions and bottom-screen placement to facilitate seamless one-handed operation.

## Colors

The color system uses deep emerald as the primary identifier, anchoring reliability, commercial prosperity, and instant WhatsApp association. A refined slate neutral palette establishes hierarchy without harsh contrast.

### Palette Application
- **Primary Emerald (`#047857`):** Primary triggers, active bottom navigation tabs, system confirmations, and brand focal points. Its hover state (`#065F46`) provides crisp tactile feedback, while `primary-soft` (`#ECFDF5`) acts as a dedicated backdrop for operational bot status components.
- **Neutrals & Surfaces:** Canvas backgrounds rely on `#F8FAFC`, avoiding stark glare in outdoor and kitchen setups. Interactive cards and elevated sheets use `#FFFFFF`, distinguished by hairline dividers (`#E2E8F0`) and structural delimiters (`#CBD5E1`).
- **Semantic Status Quadrant:** Queue management relies on four strict tripartite status combinations (background, text, and border):
  1. *Menunggu (Amber):* Background `#FEF3C7`, Text `#B45309`, Border `#FDE68A`.
  2. *Diproses (Blue):* Background `#DBEAFE`, Text `#1D4ED8`, Border `#BFDBFE`.
  3. *Selesai (Emerald):* Background `#D1FAE5`, Text `#047857`, Border `#A7F3D0`.
  4. *Dibatalkan (Crimson):* Background `#FEE2E2`, Text `#B91C1C`, Border `#FECACA`.

## Typography

The typographic hierarchy couples **Plus Jakarta Sans** with **JetBrains Mono**:
- **Plus Jakarta Sans** governs UI structure, headings, operational actions, and informational body copy. It provides open counters, friendly terminals, and high legibility at glance speed.
- **JetBrains Mono** is reserved strictly for operational codes, transaction tokens (`KO-0142`), inventory tags (`A1`, `B3`), numerical timestamps, and financial tabular data. This guarantees zero ambiguity between characters like `0` and `O` or `1` and `l` in rapid kitchen communication.

All Indonesian UI copy must observe standard capitalization rules, avoiding full uppercase blocks except for short status codes and standardized system tokens.

## Layout & Spacing

The layout is built for Android portrait viewports (standard benchmark 390x844 dp) with a disciplined 4px/8px rhythm.

### Grid & Boundaries
- **Outer Canvas Margins:** Strict `1rem` (16px) left and right gutters to maximize horizontal real estate while insulating touch targets from curved hardware edges.
- **Internal Column Grid:** 2-column distribution for dashboard metrics and menu inventory cards, using a `0.75rem` (12px) gutter.
- **Vertical Hierarchy:** Section titles, search fields, and metric cards maintain `0.75rem` to `1rem` vertical separation to retain density without visual congestion.
- **Operational Ergonomics:** Bottom navigation, floating simulator triggers, and modal actions sit within thumb-reach zones. All interactive cards allocate vertical stacking to push action buttons (`Proses Pesanan`, `Tandai Selesai`) to the outer right edge.

## Elevation & Depth

This design system avoids heavy shadows, using flat surfaces bound by structural 1px borders and selective low-opacity tints:

1. **Base Tier (Level 0):** Canvas `#F8FAFC`. Background for pages, non-interactive section groups, and horizontal divider rules.
2. **Surface Tier (Level 1):** Flat `#FFFFFF` containers bounded by `1px solid #E2E8F0`. Used for queue cards, menu catalogue units, and statistic summary cards.
3. **Elevated Overlays (Level 2):** Bottom sheets, modal dialogues, and bottom tab navigation bars. They use `background: #FFFFFF`, a top edge hairline `1px solid #E2E8F0`, and an ambient shadow: `box-shadow: 0 -4px 16px rgba(15, 23, 42, 0.04)`.
4. **Interactive Accents:** Floating actionable elements (such as the WhatsApp Simulator pill) utilize an ambient drop shadow: `box-shadow: 0 4px 12px rgba(4, 120, 87, 0.15)`.

## Shapes

The design system implements a 4-tier radius progression:
- **Small (6px):** Badges, order code tags, table row cells, and micro actions (`Sunting`, `Hapus`).
- **Medium (10px):** Form input fields, dropdown trigger containers, operational filter chips, and standard 44px buttons.
- **Card (14px):** Primary queue item cards, bot dashboard status containers, menu grid blocks, and stat summaries.
- **Pill (9999px):** Status badges (`Menunggu`, `Diproses`, `Selesai`), operational mode toggles (`TOKO BUKA`), and floating quick-action pills.

## Components

### 1. Buttons
- **Primary:** Minimum 44px height, background `#047857`, text `#FFFFFF` (Plus Jakarta Sans 600), border-radius 10px. Hover/pressed state `#065F46`.
- **Secondary / Outline:** Minimum 44px height, background `transparent`, border `1px solid #CBD5E1`, text `#0F172A`.
- **Destructive Outline:** Minimum 44px height, background `transparent`, border `1px solid #FECACA`, text `#B91C1C`.
- **Micro Actions:** 32px height, padding 4px 10px, radius 6px, Plus Jakarta Sans 600 (12px).

### 2. Status Badges & Chips
- **Status Badges:** Pill-shaped (9999px), padding 4px 10px, typography `badge-label`. Strict color pairing using the status variables (e.g., Menunggu: `#FEF3C7` fill, `#B45309` text, `#FDE68A` border).
- **Filter Chips:** 36px height, pill radius, border `1px solid #E2E8F0`, background `#FFFFFF`, text `#475569`. Active state: background `#047857`, border `#047857`, text `#FFFFFF`.

### 3. Input Fields & Dropdowns
- **Height & Spacing:** Minimum 44px height, radius 10px, border `1px solid #CBD5E1`, background `#FFFFFF`.
- **Typography:** Body-md (14px) in `#0F172A`, placeholder in `#94A3B8`.
- **Focus State:** Border `1.5px solid #047857`, subtle outline ring `0 0 0 3px rgba(4, 120, 87, 0.1)`.

### 4. Cards
- **Order Queue Cards:** Background `#FFFFFF`, 1px border `#E2E8F0`, radius 14px, padding 14px. Top row hosts the order code (JetBrains Mono) and timestamp alongside the status badge. Body content contains customer details and bold item counts. Bottom actions align flush right.
- **Bot Banner Card:** Background `#ECFDF5`, border `1px solid #A7F3D0`, radius 14px, padding 14px. Includes operational pulsating indicators and high-contrast control triggers.

### 5. Tables & Modal Bottom Sheets
- **Tables:** Sticky column headers (`#F1F5F9`), horizontal hairline row delimiters (`#E2E8F0`), with zebra striping on alternating rows (`#F8FAFC`). Order codes rendered in `label-code-md`.
- **Bottom Sheets:** Rounded top corners (radius 20px), background `#FFFFFF`, top drag handle (36px width, 4px height, `#CBD5E1`, margin 8px auto), and full-width docked action footers.
